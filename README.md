# TOEIC 英文多益複習網頁（第一版）

這是一個純前端單頁練習網站，使用 **HTML / CSS / JavaScript** 製作，無後端、無資料庫。

## 檔案結構

- `index.html`：主頁面與基本區塊（首頁統計、分類切換、題目顯示區）。
- `style.css`：卡片式介面、響應式排版、按鈕與答題提示樣式。
- `script.js`：題庫資料、分類渲染、作答判斷、錯題本、練習紀錄與 localStorage。
- `README.md`：專案說明與使用方式。

## 功能說明

- 首頁：顯示今日作答數、累積正確率、總答題數、答對題數。
- 練習分類：
  - 聽力（Part 1~Part 4，含 `audioUrl` 欄位預留）
  - 閱讀（Part 5~Part 7）
  - 單字（中翻英、英翻中）
  - 填空
  - 句子（中翻英、重組、改錯）
- 每題可立即檢查答案，顯示對錯、正確答案與解析。
- 填空練習採四選一作答（不需手動輸入），點選後立即顯示結果。
- 錯題本：自動收錄答錯題目，並可一鍵清除。
- 練習紀錄：總答題數、答對數、正確率、各類完成數。
- 重新整理後仍保留資料（儲存於 `localStorage`）。

## 如何開啟

1. 下載或 clone 專案。
2. 直接用瀏覽器打開 `index.html`。
3. 開始作答並切換分類練習。

## 備註

- 題目資料目前寫在 `script.js` 的 `sampleQuestions` 陣列中。
- 後續可把聽力題目的 `audioUrl` 補上 mp3 路徑。
