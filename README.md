# TOEIC 英文多益複習網頁

## 目前版本重點

- 保留全部頁面：首頁、聽力、閱讀、單字、填空、句子、複習清單、錯題本。
- 聽力與閱讀維持 **200 題** 並符合 TOEIC 配比：
  - Part 1：6 題
  - Part 2：25 題
  - Part 3：39 題（13 組對話 × 3 題）
  - Part 4：30 題（10 組獨白 × 3 題）
  - Part 5：30 題
  - Part 6：16 題（4 組短文 × 4 題）
  - Part 7：54 題（18 組文章 × 3 題）
- Part 2 含 Who/When/Where/Why/How/Would you/Could you/Do you know/Which/Have you 問句類型。
- 每題皆有中文解析，Part 5/6 額外包含 `grammarPoint`。
- 已修正選項安全性：使用 `data-idx`，並透過 `esc()` 避免單引號等字元破壞 HTML。
- 已實作作答鎖定：同題不可重複計分。
- 保留「我不熟」加入複習清單、錯題本、隨機出題與 `localStorage`。
- 單字 / 填空 / 句子頁面已恢復為可作答練習（各 5 題）。

## 使用方式

1. 直接開啟 `index.html`。
2. 在聽力或閱讀頁可選擇 Part 並重新隨機出題。
3. 單字、填空、句子頁面可直接四選一作答。
4. 點擊「我不熟」可加入複習清單。
5. 可在複習清單與錯題本持續追蹤弱點題目。
